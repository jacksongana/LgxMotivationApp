#Projet : LGXmotivation
Type : Application mobile (Projet de licence)
Technologies : React.js, Expo Go, Node.js, API locale, Base de données locale

Description :
Dans le cadre de ma licence en développement d'applications, j’ai réalisé une application mobile appelée LGXmotivation.
Cette application permet aux utilisateurs de consulter des images et citations de motivation.
Pour accéder au contenu, l’utilisateur doit se connecter via une interface sécurisée.

Développement du front-end avec React.js et Expo Go

Création d’une API locale en Node.js pour gérer l’authentification et les données

Mise en place d’une base de données locale pour stocker les utilisateurs et les contenus
