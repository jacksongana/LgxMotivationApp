Projet : LGXmotivation
Type : Application mobile (Projet de licence)
Technologies : React.js, Expo Go, Node.js, API locale, Base de données locale

Description :
Dans le cadre de ma licence en développement d'applications, j’ai conçu une application mobile nommée LGXmotivation, destinée à inspirer les utilisateurs à travers des citations motivantes accompagnées d’images.
L’accès au contenu se fait via une authentification utilisateur sécurisée.

Fonctionnalités principales :

🔐 Connexion : système de login via une API locale (Node.js)

🌟 Citations et images de motivation : affichées après authentification

📊 Calcul de l’IMC : saisie du poids, de la taille et du sexe, puis calcul automatique de l'IMC et estimation des calories journalières recommandées

🏋️‍♂️ Suggestions d’exercices : liste d’exercices adaptés pour entretenir la motivation et la santé

💾 Données stockées localement via une base de données locale
